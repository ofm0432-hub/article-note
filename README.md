# 기사 프로젝트 노트

기사 프로젝트의 진행 상황을 적어 두는 웹 페이지입니다. `index.html` 파일 하나로 동작하며, 별도 설치나 서버가 필요 없습니다.

## 기능

- 프로젝트 한 줄 소개와 내 역할 입력
- 주제 입력 (기본값: 경제)
- 할 일 5개 입력 및 완료 체크
- 날짜별 한 줄 기록 (11/18부터 시작, "다음 날짜 추가" 버튼으로 하루씩 추가)
- 입력 내용 자동 저장
- 휴대폰·PC 화면 지원, 다크 모드 지원

개인정보(이름, 전화번호, 주소 등)를 입력하는 칸은 없습니다.

## 사용 방법

1. `index.html`을 내려받습니다.
2. 브라우저에서 파일을 엽니다.
3. 각 칸에 내용을 입력합니다.

## GitHub Pages로 배포

1. `index.html`을 저장소에 올립니다.
2. 저장소의 Settings → Pages로 이동합니다.
3. 브랜치를 선택하고 폴더는 `/ (root)`로 지정한 뒤 저장합니다.
4. 안내되는 주소로 접속합니다.

## 저장 방식

입력한 내용은 브라우저의 `localStorage`에 저장되며, 서버로 전송되지 않습니다.

- 같은 기기, 같은 브라우저, 같은 주소에서만 다시 볼 수 있습니다.
- 다른 기기나 다른 주소에서 열면 내용이 보이지 않습니다.
- 브라우저의 사이트 데이터를 삭제하면 저장된 내용도 삭제됩니다.

## 파일

- `index.html`: 페이지 전체 (HTML, CSS, JavaScript)
- `README.md`: 설명서
